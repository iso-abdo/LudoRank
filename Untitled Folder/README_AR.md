# بروتوتايب واجهة مباراة LudoRank للموبايل

هذا البروتوتايب منفصل عن `MatchGamePage` الحالية، ومصمم لمعاينة توزيع عناصر الشاشة على الموبايل قبل دمجه في المباراة الحقيقية.

## ما الذي يفعله؟

- يعرض اللوحة الحالية عبر `LudoBoard` و`LudoBoardGeometry` و`LudoPaths` الموجودة في المشروع، دون تعديلها.
- يحافظ على أماكن الألوان ومساراتها الحالية: الأخضر أعلى اليسار، الأصفر أعلى اليمين، الأحمر أسفل اليسار، والأزرق أسفل اليمين.
- يوزع أقسام اللاعبين حول اللوحة: الأخضر والأصفر أعلى، والأحمر والأزرق أسفل.
- اللاعب الحالي فقط يظهر له زر رمي النرد، وجه النرد، وقائمة الرميات التجريبية المتاحة.
- اللاعبون غير الحاليين يظهر منهم الاسم فقط، بلا زر أو نتيجة نرد أو قائمة رميات.
- يضيف علامة قفل/فتح صغيرة عند مدخل Home Lane للاعبين المشاركين لتوضيح الشكل المرئي للحالة.
- يتيح تبديل المعاينة بين مبارزة لاعبين أو 3 أو 4 لاعبين، والتنقل بين اللاعبين لمراجعة شكل الحالات المختلفة.
- أدوات النرد وانتقال اللاعب هنا محاكاة للواجهة فقط؛ لا تستدعي `LudoGameEngine` ولا تحرك القطع ولا تطبق أي قاعدة لعب.

## الملفات

انسخ مجلد `lib/` الموجود داخل الحزمة إلى جذر مشروع `LudoRank` واسمح بدمج الملفات الجديدة. لا توجد ملفات قائمة سيتم استبدالها؛ جميع المسارات المضافة جديدة.

## تشغيل المعاينة

من جذر مشروع Flutter:

```bash
flutter pub get
flutter run -t lib/ludo_match_prototype_main.dart
```

يمكن أيضًا تجربة التحليل الساكن:

```bash
flutter analyze lib/ludo_match_prototype_main.dart lib/features/ludo_game/presentation/pages/ludo_match_prototype_page.dart lib/features/ludo_game/presentation/widgets/prototype
```

## ضمانات النطاق

لم يتم تضمين أي تعديل لـ `LudoGameEngine` أو القواعد أو `ludo_paths.dart` أو `ludo_board_geometry.dart` أو `ludo_board.dart` أو `MatchGamePage`. البروتوتايب يعيد استخدام اللوحة الموجودة فقط، ويضيف طبقة عرض مستقلة.

**ملاحظة:** الملف `lib/ludo_match_prototype_main.dart` مدخل تشغيل مؤقت مستقل، لذلك لا تحتاج لتغيير `lib/main.dart` أو الـ router لفتح المعاينة.
